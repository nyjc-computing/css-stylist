        Styling Nyla's portfolio
        
    
  
        
  
        
    
        Nyla's page (index.html) is finished and correct — it just looks plain, because its
       stylesheet (style.css) barely exists. Your job: fill in the CSS rules until the preview
       matches the reference design and the quest list is all green.
        
    
        
      error — the browser drops this code; the page keeps its default look.

        How to work
        
    
          
      
        1. Open the index.html tab: Nyla's elements already carry class="…" and
          id="…" attributes — those are the handles your CSS grabs onto.
          2. 
      
        2. style.css starts with one rule set up for you: the property is written and the
          value is missing. The first quest item tells you which colour goes there — fill it in,
          then add declarations of the same shape, property: value;, inside the
          other empty rules.
          3. 
      
        3. Hover anything in the preview to identify it: a chip shows the
          element's tag, its classes and id — exactly what you would write as a
          selector in style.css.
          4. 
      
        4. The quest list under the preview ticks off each item once the browser really applies
          it — every item tells you the exact colour and measurement to use; choosing the right
          property for the job is your part.
          5. 
      
        5. Hover the Reference button (top right of the preview) to peek at one possible finished
          look; click it to pin the reference open.
          6. 
      
        6. Anything the browser will silently ignore gets a squiggly underline — put the cursor on it
          for a plain-English explanation and a fix.
          7. 
    
        
    
        Selector shapes this page needs
        
    
        
      
        ShapeWhat it selects
        
      
        h2 { … }every <h2> element — an element selector
        
      
        .section { … }every element with class="section" — a class selector (the dot is required)
        
      
        #footer { … }the one element with id="footer" — an id selector (the hash is required)
        
      
        th, td { … }both kinds of table cell — a group of selectors, comma-separated
        
      
        .section h2 { … }only the <h2> elements inside a .section — a descendant selector
        
    
        
    
        What the Stylist checks
        
    
        
      
        CheckExample
        
      
        Missing coloncolor red; — a declaration needs color: red;
        
      
        Missing semicoloncolor: red background: white — one declaration must end before the next begins
        
      
        Missing { or }a rule opened with { but never closed
        
      
        Stray }a closing brace with no rule open
        
      
        Declarations outside a rulecolor: red; written before any { — including HTML pasted into the stylesheet (index.html is read-only; style it from here)
        
      
        Unknown propertycolour: red, font wight: bold — the browser drops the whole declaration
        
      
        Invalid valuemargin: 20 (missing px), color: navy blue, font-size: big
        
      
        Selector matches nothing.sectoin { … } — a typo'd class or id selects zero elements, silently
        
      
        Invalid selector.section!! { … } — the browser drops the entire rule
        
      
        Invisible charactersa non-breaking space copied from a slide or chat app looks like a space but isn't — the browser drops the declaration silently; the Stylist points right at it
        
    
        
    
        A beginner's CSS toolbox
        
    
        Everything the quest needs is in here — click a property to open its MDN page:
        
    
        
      
        PropertyWhat it does
        
      
        colortext colour — color: darkblue; or color: #16324c;
        
      
        background-colorthe fill behind an element — titles, table headings, cards
        
      
        font-familythe typeface — e.g. font-family: Arial, sans-serif;
        
      
        font-sizetext size — font-size: 14px;
        
      
        font-weightbold or normal
        
      
        font-styleitalic
        
      
        text-alignleft, center, right
        
      
        text-decorationunderlines on links — none to remove them
        
      
        letter-spacingspace between letters — letter-spacing: 2px;
        
      
        list-style-typelist bullets — square, none…
        
      
        marginspace outside an element — margin: 16px;; margin: 16px auto; centres a block
        
      
        paddingspace inside an element, between its content and its border
        
      
        bordera line around an element — border: 1px solid gray;; also per side: border-bottom, border-left…
        
      
        border-radiusrounded corners — border-radius: 8px;
        
      
        max-widthcap an element's width — max-width: 700px;
        
      
        border-collapsemerge table cells' borders into one clean grid — border-collapse: collapse;
